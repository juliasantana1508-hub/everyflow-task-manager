# EveryFlow

O **EveryFlow** é uma aplicação de gerenciamento de tarefas desenvolvida com **React e TypeScript**, criada para facilitar a organização das atividades do dia a dia.

A proposta do projeto é oferecer uma interface simples e intuitiva para criar, visualizar, concluir e gerenciar tarefas, colocando em prática conceitos de desenvolvimento front-end e construção de interfaces interativas.

## 🚀 Tecnologias

* React
* TypeScript
* HTML5
* CSS3
* JavaScript

## ✨ Funcionalidades

* Adicionar tarefas
* Visualizar tarefas cadastradas
* Marcar tarefas como concluídas
* Remover tarefas
* Organização simples e intuitiva das atividades

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em **React, TypeScript, componentes, gerenciamento de estado e desenvolvimento de interfaces web**.
